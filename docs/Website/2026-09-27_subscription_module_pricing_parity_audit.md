## PriceIQ decision

PriceIQ is already included with Growth Lite, so a second module fee on that plan would double-charge the core capability. Growth Lite includes two lists. The local catalogue and generated website payload now offer the existing `extra_price_lists` pack on Growth Lite and Growth: R200/month for three more lists, up to two packs. Growth Lite can therefore reach 5 or 8 lists; Growth can reach 8 or 11. Professional and higher have unlimited lists. The guarded SQL and Edge billing changes are live; app and user-published website release and hosted purchase acceptance remain. See `2026-09-27_pricing_comparison_cleanup_and_priceiq_option.md` and `docs/PriceIQ/2026-09-27_growth_lite_extra_price_lists_pack.md`.

## Remaining release decisions and risks

1. **RFID price parity:** approved new-proposal R2,490 versus current R1,490 catalogue, PayFast and SQL billing. This is above 10% commercial and billing risk if sold at the new price without a guarded coordinated rollout. Existing subscriptions need an explicit grandfathering rule.
2. **Controlled modules:** JobIQ and BrandIQ still need directory pages and launch decisions; Trade Portal is labeled assisted rollout on pricing; CashIQ, DeliveryIQ, CourierIQ and TimeIQ now have accurate directory badges but still need product readiness before general availability. Overstating availability has above 10% onboarding and expectation risk.
3. **Capacity pack usability:** AI credits require the relevant AI capability and ProjectsIQ storage requires ProjectsIQ; the pack cards explain the price and eligible base plans, while in-app activation must enforce the prerequisite. Confirm hosted checkout and annual/USD display after publication.
4. **Website publication:** local source and generated payload changes are not a deployed website or app release. The user publishes website code through GitHub. No Netlify deploy was run.

Website presentation risk is expected below 10% because prices and eligible plans are read from the generated catalogue. The RFID plan correction reduces an identified free-access mismatch; it needs app release validation, particularly any existing Scale organisation that relied on the incorrect local feature grant. Database RFID guards already require the paid pack.
